# passbch

Play a one-minute Bitcoin Cash game in your terminal while Claude Code (or any AI agent) is thinking. Every result is written to Bitcoin Cash and can be verified.

```
npx passbch                 # play: Rock·Paper·Scissors, Up or Down, Prompt Fight, Coin Flip, Typing Race
npx passbch race <id>       # join a friend's typing race
npx passbch join <id>       # join a friend's Rock·Paper·Scissors duel
npx passbch fight <id>      # join a friend's Prompt Fight
```

Or install once: `npm i -g passbch`, then just type `passbch`. Needs Node.js 18+. Web version: https://passbch.vercel.app
